# Portfolio Website

A modern, responsive portfolio website template built with HTML, CSS, and JavaScript.

## Features

- **Modern Design**: Clean, professional layout with beautiful animations
- **Responsive**: Works perfectly on desktop, tablet, and mobile devices
- **Smooth Animations**: Fade-in effects and hover animations for better user experience
- **Interactive Navigation**: Fixed header with smooth scrolling to sections
- **Project Showcase**: Grid layout for displaying your work with hover effects
- **Contact Form**: Functional contact form with glassmorphism design
- **SEO Friendly**: Semantic HTML structure

## Sections

1. **Hero Section**: Eye-catching introduction with gradient background
2. **About**: Personal information and skills showcase
3. **Projects**: Portfolio of your work with project cards
4. **Contact**: Contact information and contact form
5. **Footer**: Social links and copyright

## Customization

### To personalize this portfolio:

1. **Replace `[Your Name]`** in the HTML with your actual name
2. **Update the About section** with your personal information
3. **Replace project examples** with your actual projects
4. **Add your contact information** in the contact section
5. **Update social media links** in the footer
6. **Replace placeholder images** with your project screenshots

### Project Images
The template uses placeholder images from `https://via.placeholder.com/400x200`. Replace these with:
- Screenshots of your projects
- Proper alt text for accessibility
- Optimized images for web (WebP or compressed JPG/PNG)

### Colors and Styling
The main color scheme uses purple gradients. To change colors, edit the CSS variables in `styles.css`:
- Primary gradient: `#667eea` to `#764ba2`
- Text colors: `#333` (dark) and `#666` (medium)
- Background: `#f8f9fa` (light gray)

## Getting Started

1. Open `index.html` in your web browser
2. Customize the content to match your information
3. Replace placeholder images with your project screenshots
4. Deploy to your hosting platform of choice

Simply upload the files to your hosting platform and your portfolio will be live!
